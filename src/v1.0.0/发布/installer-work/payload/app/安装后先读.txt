QQ抓取监控安装后先读
====================

版本：v1.0.0
作者：绿头君
QQ：3630375135

用户需要自行完成：
1. 安装并登录 QQ，加入指定群聊。
2. 安装并登录游戏，进入需要点击的页面。
3. 在 UI 中输入 NapCat 使用的 QQ 号，并保存 NapCat 配置。
4. 启动 NapCat，按界面完成 QQ 登录。
5. 在 UI 中填写群号、监听对象、关键词。
6. 在“点击设置”里采集本机坐标并测试。

默认状态：
- 安全模式开启，只监听不点击。
- 自动点击关闭。
- 不带原作者的日志和坐标。

如果保存 NapCat 配置提示权限不足，请右键桌面快捷方式，选择“以管理员身份运行”。

卸载：
- 开始菜单 → QQ抓取监控 → 卸载QQ抓取监控。
- 或 Windows 设置 → 应用 → 已安装的应用 → QQ抓取监控 → 卸载。
- 卸载只删除本程序、配置、日志和快捷方式；不会删除 QQ、游戏或 NapCat。
