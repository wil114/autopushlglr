工作链路
--------

运行状态
--------
config.json 中 automation_enabled 当前为 true。命中后会激活游戏窗口并执行4步真实点击。
仍有以下保护：
1. 找不到指定游戏窗口就取消。
2. 游戏客户区尺寸与采集尺寸不同就取消。
3. 游戏未处于前台或执行中失去前台就取消。
4. 同一时间只允许一个点击序列；后续重复命中会跳过。
5. 点击完成或失败后进入触发冷却；冷却期间的新命中会跳过。
6. Ctrl+C 停止监控；点击执行期间按 Esc 可中止。

重新采集坐标
------------
1. 启动《无尽的拉格朗日》PC版，把窗口大小、分辨率、界面缩放固定好。
2. 进入收到上架消息后应开始操作的游戏页面。
3. 双击“采集点击位置.bat”。
4. 按实际购买顺序，把鼠标移动到每个位置并按 F8；记录后切回命令窗口，填写该步点击前等待时间（毫秒）。已有坐标时会从下一步继续追加，不会覆盖。
5. 全部记录后按 F9，会生成“点击位置待确认.json”。按 Esc 可取消。
6. 新坐标必须重新写入 config.json 后才会用于正式自动点击。

注意：采集时不要实际点击购买按钮，只需悬停后按 F8。

测试与启动
----------
启动UI.bat：打开桌面 UI，可查看状态、修改配置、启动/停止监听、调用坐标工具、查看命中记录。
UI 中“安全模式”只监听不点击；“正式模式”命中后会按点击步骤真实点击。
UI 点“启动监听”前会检查 NapCat 端口、群号/关键词/监听对象、正式模式下的游戏进程和点击步骤。
运行自测.bat：验证消息过滤、组合关键词和去重，不连接 QQ、不点击。
模拟点击流程.bat：显示当前点击配置，不移动鼠标、不点击。
预览已采集位置.bat：激活游戏并依次移动鼠标到已采集位置，绝不点击。
设置点击等待时间.bat：逐步修改已有位置的点击前等待时间，直接回车保留原值。
真实点击测试.bat：3秒倒计时后先移动到游戏客户区 (0,0)，再按已填写的等待时间真实点击；按 Esc 可中止。
清除全部点击位置.bat：输入 CLEAR 后清空当前坐标并从步骤1重新开始；原文件会移到“已清除记录”备份目录。
启动监控.bat：连接 NapCat 并运行正式监控。

配置字段
--------
keyword_match：all 表示所有关键词都要出现；any 表示任意一个出现。
automation_enabled：只有 true 才可能点击；坐标未确认前保持 false。
trigger_cooldown_ms：一次点击流程结束后的触发冷却时间；冷却期间新命中会被忽略。
game_process_name：游戏进程名，默认 infinite_lagrange_cn。
expected_client_width / expected_client_height：采集时的游戏客户区尺寸。
focus_wait_ms：激活游戏窗口后的等待时间。
click_steps：按顺序执行的固定坐标步骤；坐标相对游戏客户区左上角。
delay_ms：执行当前步骤点击前等待的毫秒数，例如 1500 表示等待1.5秒。

单个 click_steps 示例
---------------------
{
  "name": "点击购买",
  "x": 1000,
  "y": 700,
  "delay_ms": 100,
  "clicks": 1,
  "interval_ms": 50
}

发布安装包
----------
发布\QQMonitorSetup.exe：给其他用户使用的安装包。
安装时可自行选择位置；程序实际安装到所选位置下的 QQMonitor 文件夹。
安装包使用干净模板：默认安全模式、自动点击关闭、不携带当前电脑日志和坐标。
卸载方式：开始菜单 → QQ抓取监控 → 卸载QQ抓取监控；或 Windows 设置 → 应用 → QQ抓取监控 → 卸载。
卸载只删除本程序、配置、日志和快捷方式；不会删除 QQ、游戏或 NapCat。

限制
----
固定坐标方案依赖游戏界面布局保持不变；弹窗、遮挡、网络延迟或界面改版都可能让步骤失效。程序会防止窗口/尺寸错误，但不能理解游戏按钮状态，也不能保证一定抢购成功。
